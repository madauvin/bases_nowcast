# Vintages hebdomadaires — Nowcast du PIB français (OFCE)

Ce dépôt archive les vintages hebdomadaires de la base de données conjoncturelles utilisée pour le nowcasting du PIB français à l'OFCE. Chaque fichier correspond à l'état de la base à une date donnée, permettant des analyses en temps réel (*real-time analysis*).

## Contenu

Chaque vintage est un fichier `.csv` horodaté, structuré de manière identique, et contenant l'ensemble des séries conjoncturelles intégrées dans le modèle à facteurs dynamiques. Les séries couvrent les domaines suivants : activité, commandes et inventaires, construction, finance, incertitude, international, marché du travail, monnaie-crédit-prix.

## Fréquence de mise à jour

La base est mise à jour chaque mardi matin. Un nouveau vintage est archivé à chaque mise à jour.
